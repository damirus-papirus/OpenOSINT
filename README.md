# OpenOSINT

Небольшой CLI-инструмент для **проверки публичных технических данных** и аккуратного сбора ссылок на открытые источники. Python 3.10+, без сторонних зависимостей; подходит для Termux и Windows.

## Что умеет

- распознавать домен, IP, URL, email, телефон и username;
- получать DNS-записи через публичный DNS-over-HTTPS;
- смотреть публичные RDAP-данные IP/домена;
- находить корректные DNS-имена домена в публичных записях Certificate Transparency через crt.sh;
- по флагу `--check-subdomains` проверить DNS A/AAAA для максимум 15 найденных имён (без сканирования портов);
- проверять ограниченный список публичных страниц профилей по username (только HTTP-статус, без сбора личных данных);
- показывать прогресс проверки в терминале; при необходимости отключать его через `--no-progress`;
- выводить краткий отчёт в терминале или подробный через `--verbose`;
- сохранять полный JSON и автономный HTML-отчёт.

**Не ищет владельцев телефонов/аккаунтов, адреса проживания, платёжные данные, родственников, закрытые базы или утёкшие данные.** Совпадение username не доказывает, что аккаунты принадлежат одному человеку. Используйте только для законной проверки своих активов или разрешённых публичных данных.

## Запуск

### Termux (Android)
```bash
pkg update
pkg install python git -y
git clone https://github.com/damirus-papirus/OpenOSINT.git
cd OpenOSINT
python main.py example.com
```

### Windows
Установите Python 3.10+ с python.org, затем в PowerShell:
```powershell
git clone https://github.com/damirus-papirus/OpenOSINT.git
cd OpenOSINT
py main.py example.com
```

## Примеры

Краткая проверка домена:
```bash
python main.py github.com
``

Проверить DNS у максимум 15 найденных имён:
```bash
python main.py github.com --check-subdomains
``

Сохранить полный отчёт:
```bash
python main.py github.com --json report.json --html report.html
``

Подробный вывод в терминале:
```bash
python main.py github.com --verbose
``

Другие варианты:
```bash
python main.py 8.8.8.8
python main.py https://example.com
python main.py user_name --profiles
python main.py someone@example.com
python main.py "+1 (202) 555-0123"
``

Откройте созданный `report.html` в браузере. В HTML-отчёте подробности каждого источника раскрываются по нажатию на «Показать подробности».

## Ограничения

- Для сетевых проверок нужен интернет.
- Сайты могут блокировать запросы или менять API; ошибка источника не означает отсутствие данных.
- Сертификат Transparency не доказывает, что имя сейчас активно. DNS-ответ тоже не гарантирует, что веб-сайт доступен.
- Проверка поддоменов ограничена 15 именами и запрашивает только DNS A/AAAA; порты и содержимое сайтов не проверяются.
- Email и телефон проверяются только по формату/публичной технической информации, без определения владельца.
- Не вводите секреты, пароли, токены или чужие чувствительные данные.
